# 日报/周报知识库记录原则

> 核心判断标准：这条信息如果今天不记，30 天后看月报数据时会不会少了一个重要的上下文？

## 核心区分：邮件报告 ≠ 知识库文件

| | 邮件日报/周报 | 知识库 daily/weekly-insights.md |
|---|---|---|
| 给谁看 | 用户（人类） | AI（下次分析用） |
| 格式 | 完整报告，有图表、预算表、饼图 | 精简记录，只记关键信息 |
| 目的 | 通知用户财务情况 | 给未来分析提供上下文 |

**邮件报告可以详细**（有表格、逐笔分析、预算全景），**知识库只记精简摘要**。不要把邮件报告内容照搬进知识库。

## 值得记录的七大类

### ① 异常值
- 单日消费显著偏离日常基线（如突然 ¥1,500）
- 某个分类首次出现或消失
- 重复扣款、记账错误

### ② 首次/里程碑
- 新消费分类（鞋服、医疗、零食）
- 新支付方式（1688 先采后付）
- 新行为模式确立（饮料囤货策略从信号变成稳态）

### ③ 状态变更
- 持续跟踪事项的进展（DeepSeek 扣款已核实、医院押金待结算）
- 之前标记的问题解决了
- 用 ✅/⏳ 标记闭环状态

### ④ 有后续影响的事
- 已购买但未消费的（演唱会门票、酒店预订）
- 承诺/计划类的支出（下月有某笔大额要来）

### ⑤ 收入上下文
- 发薪日、报销到账、退款、副业首笔收入
- 解释某笔大额消费是因为资金宽裕还是冲动

### ⑥ 周期性义务变更
- 新开订阅/会员、自动续费关闭、免费试用到期日
- 单次金额小但有复利效应，漏记可能造成后续扣款困惑

### ⑦ 债务/信用事件
- 首次使用分期、花呗/白条借款、信用卡临时提额、最低还款
- 改变未来现金流约束，需长期跟踪

## 不记录的

- 每天三餐/饮料/单车的逐笔记录（除非异常，如连续 N 天零消费后破戒）
- 完整预算全景表（月报里有，日报不需要重复）
- 数据源说明（yimu_bill_xxx.xlsx，备份截止...）
- 重复的趋势分析和"核心日常上升/下降"的逐日描述
- 日常琐碎（正常三餐 ¥12、单车 ¥1、零星奖金 ¥0.58）

## 无异常时的处理

> ⚠️ **不能省略日期**。即使当天无任何值得记录的事项，也要保留 `### MM/DD` 并注明：

```
### 05/11
- 无异常，日常消费
```

周报同理：`- 无异常，消费平稳`

## 情绪标签：不采用

DeepSeek 建议记录消费背后的情绪诱因（情绪性消费、促销倒计时、社交压力等）。
**不采用**：需要用户自报，AI 从账单数据猜不出来，强行贴标签反而不准确。

## 适用范围

以上原则同时适用于日报和周报的知识库文件。周报聚焦更宏观的维度：
- 支出结构的重大变化
- 行为模式演化（如连续 N 天零消费确立为习惯）
- 非常规支出事件
- 预算执行关键节点
- 持续跟踪事项的进展/闭环
- 下周需关注的风险点

## 格式示例

```markdown
## 2026-W20（05/11 - 05/17）

### 05/11
- 无异常，日常消费

### 05/12
- 送礼 ¥238（afterlaundry 睡眠障碍俱乐部 T恤），潮牌文化消费
- DeepSeek 第四次扣款 ¥10，四连扣合计 ¥48.06

### 05/15
- 🏥 医院二次消费 ¥1,110（蚌埠医科大学），5月医疗累计 ¥1,683
- 🏨 演唱会住宿 ¥358（南京丽笙），演唱会全成本 ¥1,346
- ⏳ 待跟进：医院 ¥100 押金待结算

### 05/17
- 全日仅 1 笔三餐 ¥4.20，校园极简日
```

不限行数，只写值得记录的内容。无异常时必须注明，不能省略。
