## 裁剪算法伪代码

```python
def trim_knowledge_file(filepath: str, max_blocks: int):
    """按 --- 分段裁剪，保留最后 max_blocks 个块。"""
    content = read_file(filepath)

    # 分离全局段落（第一个 --- 之前的内容）和数据块
    parts = content.split('\n---\n')

    # 第一个 part 可能包含文件头部 + 第一个数据块
    # 需要判断：如果第一个 part 包含 # 标题，分离头部
    header = ''
    blocks = parts
    if parts[0].startswith('#'):
        # 找到第一个数据块的起始
        first_block_start = parts[0].find('\n## ')
        if first_block_start > 0:
            header = parts[0][:first_block_start] + '\n'
            blocks = [parts[0][first_block_start:]] + parts[1:]

    # 保留最后 max_blocks 个块
    if len(blocks) > max_blocks:
        kept_blocks = blocks[-max_blocks:]
    else:
        kept_blocks = blocks

    # 写回：头部 + 保留的块（用 --- 连接）
    result = header + '\n---\n'.join(kept_blocks)
    if not result.endswith('\n'):
        result += '\n'
    write_file(filepath, result)
```
